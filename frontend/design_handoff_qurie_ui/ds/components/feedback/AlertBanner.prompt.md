Sits at the top of the content region, inside `<main>`, above the data it describes. Title states what happened, description states what to do. Max one banner visible at a time.
```jsx
<AlertBanner tone="error" icon={<AlertCircle size={15} />} title="초대 3건이 전송되지 않았습니다" description="이메일 주소 형식을 확인해 주세요." actionLabel="자세히" />
```
