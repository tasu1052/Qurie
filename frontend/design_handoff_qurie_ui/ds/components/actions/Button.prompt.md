Qurie button — use for all actions; primary is solid black, never indigo except the rare 'accent' variant.
```jsx
<Button variant="primary">초대 보내기</Button>
<Button variant="secondary">취소</Button>
<Button variant="ghost" size="sm">더 보기</Button>
```
Variants: primary | secondary | ghost | accent. Sizes sm/md. `disabled`, `icon` (16px node).
